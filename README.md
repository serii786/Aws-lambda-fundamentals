# ⚡ AWS Lambda Fundamentals

> Learn Serverless Computing from Zero to Hero.

## What is AWS Lambda?
AWS Lambda is a serverless compute service. You upload code, AWS runs it on events. No server to manage.

## How It Works
1. **Trigger:** S3 Upload / API Call / DB Change
2. **Execute:** Lambda runs your code
3. **Scale:** Auto-scales 0 to 1000s
4. **Pay:** Pay only for milliseconds used
