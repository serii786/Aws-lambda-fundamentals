What is AWS Lambda?

AWS Lambda is a serverless compute service. You upload your code, AWS runs it when an event happens. No server to manage.

How It Works? - 4 Steps

1. Trigger

Event happens - S3 Upload, API Call, DB Change

2. Execute

Lambda runs your code automatically

3. Scale

Auto-scales from 0 to 1000s of requests

4. Pay

Pay only for milliseconds your code runs

Lambda vs EC2
